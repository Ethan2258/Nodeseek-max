# sb.sb 论坛体验对照

[返回首页](../README.md) · [使用说明](usage.md) · [开发指南](development.md)

本页记录 2026-11-02 检查到的公开论坛前端及 NodeSeek Max 的对应实现。参考入口是 [sb.sb 首页](https://sb.sb/) 与[投票帖](https://sb.sb/t/15295/)；站点专属业务与论坛浏览体验分开判断。

## 可在 NodeSeek 使用的体验

| 场景 | 对应实现 |
| --- | --- |
| 首页与手机导航 | 圆角主题、版块、个人入口、热榜、最近浏览，复用已有缓存 |
| 帖子与评论 | 作者栏、楼号、引用卡片、简洁模式、原生置顶与操作 |
| 阅读与定位 | 标题小页码、我的回复楼层、代码复制、图片预览、长引用折叠 |
| 投票 | 独立卡片、票数与百分比、已选进度、公开名单展开，保留原生表单 |
| 抽奖 | 规则、倒计时、结果入口、参与楼层及已参与标记 |
| 回复与私信 | Markdown、附件、表情、草稿、提交状态与消息阅读 |
| 个人与通知 | 资料、关注与粉丝、备注、黑名单过滤、未读同步 |
| 本次补齐 | 列表与帖子标题的已回复 / 已参与、跨标签页更新、每页楼数跳转与外部抽奖原帖定位 |

“已回复 / 已参与”使用 sb.sb 通用 topic-badge 的胶囊尺寸及现有主题的状态色，数据来自 NodeSeek 与本机记录。它们表示已记录的状态，不能代替发帖人设定的额外参与条件。

## 本次公开资源检查

- 样式：index.114b17acd3.css，SHA-256 为 114b17acd34d81b6ba18d76e1047ce930a7390e034455399e0395de1ee446544。
- 论坛脚本：index.bf732d57fe.js；全局应用脚本：app.c8a556589c.js。仅作静态检查，不在本地执行下载的代码。
- 与上一次记录的样式相比，新增选择器集中在个人资料 UID 的排除规则与文档正文。NodeSeek Max 的 UID 已使用独立字号规则；文档页专用规则不加入论坛页面。

银行、商城、证券、红包结算、游戏资产等依赖 sb.sb 自己的账号、数据库与服务，不能用 NodeSeek 的前端脚本生成对应业务数据。需要站点接口支持的功能，应先确认 NodeSeek 提供的能力，再实现可操作的界面。

## 性能约束

- 状态标签复用“我的回复”，不扫描其他帖子、不新增轮询或请求。
- 有效规则与参与证据有数量上限，记录变化才写入；静止时不反复改标签。
- 缓存标签在首帧前绘制；新增回复只更新相关状态，同步使用浏览器 storage 事件。
- 回归检查静止 DOM、首屏布局、请求数量，以及深浅色和窄屏；性能比较使用相同页面和三次中位数。
