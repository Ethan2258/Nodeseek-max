# 使用与设置

[返回首页](../README.md) · [安装帮助](installation.md)

## 常用入口

| 入口 | 作用 |
| --- | --- |
| 顶栏齿轮 | 打开 NodeSeek Max 设置 |
| 手机左上角菜单 | 个人入口、版块、快捷功能，以及热榜和最近浏览 |
| 回复区的格式 / 附件 / 表情 / 预览 | 编辑或检查正文，发布仍由论坛原生表单处理 |
| 回复区“只看楼主 / 直达底部 / 简洁模式” | 筛选、定位或切换评论布局 |
| 评论操作中的“置顶 / 取消置顶” | 原站权限允许时，操作对应评论，保留原生确认流程 |
| 资料卡等级标签 | 查看等级与每日鸡腿进度 |
| 名字后面的活跃度标签 | 悬停查看日均主题、回帖和注册天数；档位说明见下方 |
| 标题前的已回复 / 已参与 | 查看本机记录的回帖与抽奖参与状态；楼层链接仍在“我的回复”一行 |

## 设置分类

改动自动保存，刷新后完整应用。可以搜索选项；总开关关闭后，该组子选项暂时不可操作。

| 分类 | 常用选项与作用 |
| --- | --- |
| 外观 | 列表标题字号、字体、深浅色、导航与侧栏内容 |
| 浏览 | 中文时间、图片、复制、引用折叠、预览、翻页等阅读行为 |
| 用户 | 用户备注、活跃度标签、屏蔽、资料卡、个人主页统计与通知相关增强 |
| 工具 | 编辑与上传、签到、代码等工具增强 |
| 网络 | 请求节奏、后台请求与预取相关选项 |
| 关于 | 当前版本、注入时机、预加载诊断、更新入口与兼容提示 |

保存与刷新、导入导出、默认值和边界输入均有浏览器回归覆盖；具体选项以设置面板为准。

## 已回复与抽奖参与标记

列表与帖子标题根据当前账号在本机记录的回帖显示“已回复”。已有楼层链接保留；修改论坛每页楼数后，跳转页码也按该设置计算。

抽奖规则已明确、并有证据确认在开奖前回复且达到起始楼层时，标题与抽奖卡片显示“已参与”。点击“回复参与”只打开回复框，实际回复到达后才记录参与；若规则写有额外要求，最终仍以原帖为准。已开奖的历史帖缺少回复时间时，先保留“已回复”，打开原帖取得时间后再判断参与。

同一浏览器的其他标签页收到记录变化后会同步，记录按账号区分。关闭“浏览 → 我的回复”同时关闭这两个标签；它们不增加查询请求。引用其他帖的抽奖卡片会提供“前往原帖参与”，使用原帖自己的记录。

## 活跃度标签

主题数加回帖数按注册天数折成日均（不满 1 天按 1 天算）。个人主页的“主题”“回帖”两格下面写出各自的日均，名字后面、帖子作者栏和悬停资料卡里标出档位：

| 标签 | 日均（主题 + 回帖） | 含义 |
| --- | --- | --- |
| 潜水 | 不到 0.1 | 十天不到一次，基本只看 |
| 佛系 | 0.1～0.5 | 偶尔说两句 |
| 正常 | 0.5～3 | 正常参与 |
| 活跃 | 3～10 | 常来常往 |
| 话痨 | 10～25 | 回帖很勤 |
| 肝帝 | 25～50 | 几乎整天在论坛 |
| 人机 | 50 以上 | 天天每 20 分钟一条，像挂机脚本 |

注册不满 30 天的账号只标“新号”（日均到话痨以上时同时标档位）。另外最多补一个习惯标签：日均 1 个主题以上为“高产楼主”，主题多于回帖（主题至少 10 个）为“只发帖”，一个主题没发、回帖过百为“只回帖”。标签只按公开数字计算，不代表真的是机器人；可在设置“用户 → 活跃度标签”关闭。

## 手机侧栏

- **导航**：按 sb.sb 手机圆角设计，使用单列文字版块、个人入口和快捷链接。当前版块会标出；“个人设置”是论坛设置，“脚本设置”是 NodeSeek Max 设置。
- **热榜**：复用桌面热榜的数据与缓存，打开时按需读取。关闭热榜或侧栏显示后，手机入口也会隐藏。
- **最近浏览**：查看当前账号在本机打开过的帖子；没有记录时显示说明。关闭此功能后，手机入口也隐藏。
- 点关闭、遮罩或向左滑动可收起。菜单独立滚动，关闭后回到正文原位置；外接键盘可用 Tab 和 Esc。

触屏不启动鼠标悬停预览、悬停预取或悬停资料卡。列表空白处可以打开帖子，作者、版块和页码链接保留各自的操作。

手机未保存字号时，列表标题默认 15px；已保存的字号继续生效。顶栏固定，版块条随正文滚动；列表“隐藏”入口可管理关键词屏蔽。

## 回复、草稿与快捷键

支持 Markdown、附件、表情、预览及图片粘贴上传。图片默认传到论坛官方的 NodeImage（在 nodeimage.com 登录一次即可）；也可以在「设置 → 工具 → 图片上传」换成兰空、Chevereto、简单图床、Telegraph 兼容接口或自定义接口。第三方图床经脚本管理器上传，第一次连接新图床时脚本管理器会询问是否允许；需要密钥的图床在上传按钮旁填写，密钥只留在当前页面、不保存。

电脑可使用 Ctrl / ⌘ + Enter 提交，以及 Ctrl / ⌘ + B、I、K、E 处理粗体、斜体、链接、行内代码。页面或管理器不支持编辑器桥接时，保留原生编辑器。

回复和发帖的编辑外框保留圆角，内部文字选区单独使用直角绘制层。打开“一键抽奖”可填写奖品并预览；长网址会换行，三列保持在卡片内。发帖后自动补入的开奖链接，以及卡片“查看开奖”入口，统一带一个 `mode=view` 参数。

## 投票

主楼中的投票显示在主楼与回复之间的独立圆角卡片中。每项右侧列出票数与百分比，下方显示进度；已投选项标注“· 已选”，进度使用绿色。

原投票题目、单选或多选、提交与“不排序”操作都保留。单选结果的总票数对应参与人数；多选显示总票数，避免把多次选择当成多个人。未取得结果时只显示单选 / 多选类型。

公开投票默认收起投票人头像，点击“查看投票人”展开，各头像和原生更多入口仍可使用。匿名投票没有名单时不显示该按钮。

## 本地数据

| 数据 | 保存位置与清理方式 |
| --- | --- |
| 设置、备注和屏蔽配置 | 脚本管理器存储；支持导入导出 |
| 最近浏览、我的回复与参与证据、草稿等本机记录 | 按功能和账号保存在站点本地存储中；清空站点数据可能移除这些记录 |
| 字体、用户资料、热榜、预取诊断等缓存 | 站点本地存储或会话存储；“清空缓存”会清理现用缓存 |

“清空缓存”保留设置、备注、最近浏览、我的回复、草稿与限流冷却。“恢复默认”会重置脚本选项；执行前可先导出配置。

## 请求与性能

主题与主要结构在首屏阶段整理；低优先级工作延后执行。热榜、资料与字体使用缓存，后台请求受并发和节奏限制，站点返回 429 / 503 时进入冷却。

个人主页主题帖统计默认关闭；开启后需要额外读取帖子。首次选择带网络字体的选项时会下载字体，随后缓存；“系统字体”不需要这类字体下载。

本地自动化和截图使用模拟页面。WebKit 与触屏模拟用于回归检查，不能替代特定 iPhone、Safari 和脚本管理器版本的真机体验。
