# NodeSeek Max

NodeSeek / DeepFlood 用户脚本，当前版本 **1.8.4**。界面按 [sb.sb](https://sb.sb/) 现版 1:1 复刻（配色、字体、布局、圆角），保留论坛原生编辑与提交。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. [安装最新版脚本](https://raw.githubusercontent.com/Ethan2258/Nodeseek-max/main/nodeseek-max.user.js)。
3. 停用其他 NodeSeek 增强脚本，避免重复注入。

[版本与安装文件](https://github.com/Ethan2258/Nodeseek-max/releases)

## 当前功能

- 全站 sb.sb 样式，浅色、深色变量与 sb.sb 样式表原值一致；圆角与 sb.sb 相同（卡片 12px、输入框 8px、按钮与标签胶囊）。
- 首先呈现当前页主题、过滤和编辑器，再启动热榜与其他增强；输入时不重复扫描整页。
- 桌面个人卡、八个快捷入口、紧凑今日热门、本地最近浏览十条，以及纯文字 NQ 入口。
- 个人空间使用统一的资料头部、四列统计、等级进度条和主题/评论列表分页。
- 帖子列表默认不自动翻页（设置里可打开，自动接 3 页后改为点按钮继续）；评论默认按需追加，更新底部圆形页码，当前页明确引用整理为楼中楼；评论操作在右上角，保留图标和计数。
- 回复与发帖统一 SB 编辑器，保留 Markdown、附件、表情、预览和粘贴图片（上传到论坛官方图床 NodeImage）；预览不留下空编辑器，提交仍由原站处理。
- 帖子页回复区标题栏有「只看楼主」和「直达底部」；「只看楼主」只对当前帖子生效。
- 发帖页编辑器提供“抽奖”快捷模板，一键填入抽奖标题与开奖信息字段；内容仍需手动检查，发布后的帖子链接再补到开奖链接字段。
- 追加评论优先复用兼容的原生互动组件；不兼容时，互动入口打开该评论原页。
- 通知与私信使用统一消息中心，列表先加载一页，通知正文按点击加载。
- 保留外链直达、关键词过滤、黑名单通知过滤与代码复制。顶栏支持关键词及深浅色切换。
- 深浅色支持浅色、深色和跟随系统；跟随系统只响应操作系统主题，不会被站点自己的主题类突然覆盖。
- 脚本设置按 sb.sb 重做：外观、浏览、用户、工具、网络、关于六个分页，支持搜索、恢复默认、清空缓存、导入导出配置和检查更新，改动立即保存；跟随深浅色。

头像悬停显示唯一资料卡，单个用户信息按需读取并缓存；个人空间、预览卡和搜索/主题切换均统一适配。

移除信用分、信任分、旧阅读历史模块、帖子监控、回帖足迹、重复资料卡及旧工具条。默认字体与 sb.sb 相同：系统字体 + Space Mono 数字（首次在线下载后缓存）；不想联网下载可在设置里改为「系统字体」。

## 开发

```bash
npm install --no-package-lock
npm run sb           # 编译套件、适配样式和界面桥接
npm run meta
npm run check
npm test
npm run screenshots  # 桌面浅色、深色与手机布局
npm run performance  # 与 v1.7.2 比较本地 fixture，三次中位数
```

测试需要 Chromium；可通过 `NSMAX_CHROMIUM` 指向已有 Chrome。sb.sb 1:1 复刻层在 `theme/design.css`（最后注入、优先级最高）；`theme/sb-suite.css` 只作对照快照，不再整份注入；适配在 `theme/sb-adapter.css`，回复与分页桥接在 `theme/ui-runtime.js`，消息与关于弹窗样式在 `theme/messages.css`、`theme/settings.css`。

浏览器回归使用真实结构的本地模拟页面；耗时数据不能代表论坛服务器或用户网络速度。原生接口、验证码和权限由站点处理。
